# HTML Forms Exercise – Responsive Design

##  Project Overview
This project is a simple and responsive HTML form created as part of a web development exercise.  
It demonstrates the use of HTML form elements along with CSS styling and responsive design techniques.

---

##  Technologies Used
- HTML5  
- CSS3  
- Responsive design using viewport units and media queries  


---

##  Features
- Clean and simple layout  
- Fully responsive on mobile, tablet, and desktop screens  
- Uses fieldsets and legends to group related form elements  
- Includes text inputs, textarea, checkboxes, radio buttons, and dropdown menu  

---

##  Responsive Design
- Viewport meta tag ensures proper scaling on all devices  
- CSS uses `vw` units for responsive font sizes  
- Media queries adjust text size for smaller screens  

---

##  How to Run the Project
1. Download or clone the project files  
2. Open `index.html` in any modern web browser  
3. Resize the browser window to see the responsive behavior  

---

##  Purpose
The purpose of this project is to practice:
- HTML form elements  
- External CSS styling  
- Responsive web design concepts
