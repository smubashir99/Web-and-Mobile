## Lab 5 – JavaScript Event Lifecycle

## Aim
To understand and implement the JavaScript event lifecycle using page events, user interaction events, form events, and page exit events.


---

## Events Implemented
- Page Load (`load`)
- Button Click (`click`)
- User Input (`input`)
- Text Selection (`select`)
- Form Submit (`submit`)
- Form Reset (`reset`)
- Page Exit / Reload (`beforeunload`)

---

## Key Concept
`preventDefault()` is used to stop the browser from reloading the page during form submission.

---

## Conclusion
This lab demonstrates the complete JavaScript event lifecycle.
